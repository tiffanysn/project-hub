## 新建子项目指南
当你想要开启一个新项目时，可以直接在终端或者让 AI 助手执行：
```bash
mkdir projects/<your-project-name>
```
然后在该目录下编写代码或初始化独立的工程环境（例如 `npm init`, `python -m venv venv` 等）。
