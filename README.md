# Project Hub 🚀

欢迎来到个人开发工作区 **Project Hub**！本仓库用于沉淀技术知识、积累复用技能，并集中管理日常开发与试验的各类子项目。

---

## 📂 仓库目录架构

```text
project-hub/
├── knowledge-base/       # 🧠 知识库：架构设计、参考文档、编码规范、学习笔记
├── skills/               # 🛠️ 技能库：通用脚本、AI 提示词/工作流、复用代码模板
└── projects/             # 💻 项目区：未来所有独立开发子项目的存放目录
```

---

## 📌 模块说明

### 1. [Knowledge Base (知识库)](file:///Users/xiaotongsong/project-hub/knowledge-base/README.md)
用于存储长期有效的设计思想、技术文档、速查表（CheatSheets）与技术规范。
- 无论之后开启什么项目，都可以在这里沉淀通用的知识资产。

### 2. [Skills (技能库)](file:///Users/xiaotongsong/project-hub/skills/README.md)
用于存放可以在多个项目中复用的工具与能力：
- 常用自动化脚本（如数据处理、构建打包）
- 针对 AI 协同编程的 Prompt 模板与工作流指南
- 脚手架与模板代码

### 3. [Projects (项目区)](file:///Users/xiaotongsong/project-hub/projects/README.md)
每个具体任务或产品都会在 `projects/` 下建立独立的子文件夹。
- 每个子项目拥有独立的依赖管理与说明文档，互不干扰。

---

## 🤝 协作建议
在使用 AI 助手（如 Antigravity / Claude）协同编程时，你可以直接引用：
- `knowledge-base/` 中的编码规范来指导生成代码的风格。
- `skills/` 中的模板快速起步新功能。
- 在 `projects/` 下直接创建并迭代具体项目。
